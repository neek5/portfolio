1. Carry N' Go: Automated Luggage Storage System

[🎥 Watch the Prototype in Action Here]

Context: SUTD Engineering Design Project

Role: Hardware Developer & UI Programmer

Tech Stack: ESP32 Microcontroller, IoT Integration, UI/UX Programming, Rapid Hardware Prototyping, Embedded Systems, Usability Testing, Servo Motor Control.

Project Overview

"Carry N' Go" is a smart, automated luggage storage prototype designed to alleviate spatial congestion at high-traffic transit hubs like Jewel Changi Airport. Operating on a playful yet highly functional "sushi conveyor belt" concept, the system allows visitors to safely stow their luggage, transforming bulky bags into organized, modular units. The project spanned the full engineering design cycle, from initial problem identification and low-fidelity sketching to functional usability testing and physical prototyping.

The Problem

How might we create a safer and more organized environment at Jewel Level 1, where visitors can move, rest, and dine without leaving luggage or trolleys scattered across pathways?

My Contributions & Technical Implementation

As the lead for the system's interactive and electronic components, I owned the technical execution of the physical prototype, teaching myself embedded programming to bring the concept to life.

  • Microcontroller & Hardware Integration: Engineered the core logic using an ESP32 microcontroller. I successfully programmed the board to process inputs from physical sensors and control an 8G mini servo motor, executing the lateral movement required to push luggage boxes from the conveyor belt into designated storage racks.
  • Interactive UI/UX Development: Designed and coded the user-facing digital interface that operates alongside the physical machine. The UI guides users through a playful, themed tutorial, allowing them to input luggage size/quantity and simulate a secure login (via Passport/Singpass ID scanning) to link their unique ID to their storage slot.
  • Rapid Prototyping & Agile Problem-Solving: Navigated a steep technical learning curve, iteratively coding and debugging the ESP32 logic from scratch. Bridged the gap between the software interface and the physical hardware, ensuring seamless communication between user inputs and the automated conveyor system during functional testing.

2. Seasonal Colour Analysis App

Context: Google HelloAI Hackathon

Role: AI Application Developer

Tech Stack: Generative AI, Google Gemini Pro 1.5, Streamlit, Docker, Python, Full-Stack Development.

Project Overview

Developed during the Google HelloAI Hackathon, this AI-powered application provides users with highly personalized seasonal color recommendations. By uploading a simple portrait, the tool analyzes the user's complexion and undertones to instantly output their seasonal color profile (e.g., "Soft Summer") alongside a curated, visual palette of complementary colors.

Technical Implementation

  • Generative AI Integration: Leveraged Google's Gemini Pro 1.5 model to process image inputs and drive the core analytical engine, generating accurate, tailored color profiles.
  • Frontend Development: Built a responsive, user-friendly web interface using Streamlit. Engineered seamless drag-and-drop file upload functionality and a clean dashboard to display both simplified and detailed analysis views.
  • Deployment & Architecture: Containerized the entire application using Docker to ensure reliable performance, environmental consistency, and demonstrate scalable technical problem solving.
